今天，「不语」正式开张。

## 为什么要写博客

不是为了流量，主要是为了自己：

- **记录**：生活里的事，过几个月就忘光了，写下来才算数。
- **沉淀**：技术上踩过的坑，下次遇到能直接翻出来，不用重新踩。
- **表达**：把想法写清楚，本身就是一种训练。

## 为什么选 Astro

对比过 Hexo、Hugo、VitePress 之后，选了 Astro：

- 性能极强，默认零 JavaScript，加载飞快；
- Content Collections 管理 Markdown 很规范；
- 以后想加 React / Vue 组件做花活，随时可以；
- 部署在免费托管平台上，不花一分钱。

日常写文章完全不用碰代码——就像你现在看到的这篇，就是一个 Markdown 文件。
